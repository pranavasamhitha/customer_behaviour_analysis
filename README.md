# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI. The objective is to transform raw customer transaction data into actionable business insights through data cleaning, exploratory data analysis (EDA), SQL-based querying, and interactive dashboard development.

The project demonstrates an end-to-end data analytics workflow, from data ingestion and preprocessing to visualization and reporting.

---

## Dataset

The dataset contains customer shopping records, including:

* Customer demographics (Age, Gender)
* Product details (Item Purchased, Category, Size, Color)
* Purchase information (Purchase Amount, Previous Purchases)
* Shopping preferences (Shipping Type, Payment Method)
* Customer engagement metrics (Review Rating, Subscription Status)
* Promotional information (Discount Applied, Promo Code Used)

## Project Workflow

### 1. Data Loading

* Imported dataset into Python using Pandas.
* Performed initial inspection of data structure and quality.

### 2. Data Cleaning

* Checked for missing values.
* Removed duplicates.
* Standardized data formats.
* Corrected inconsistencies where required.

### 3. Exploratory Data Analysis (EDA)

* Analyzed customer demographics.
* Identified purchasing trends.
* Evaluated category-wise sales performance.
* Studied customer ratings and subscription behavior.
* Explored relationships between variables using visualizations.

### 4. SQL Analysis

Executed SQL queries to answer business questions such as:

* Top-selling product categories
* Customer purchase patterns
* Revenue distribution across categories
* Subscription-based customer insights
* Impact of discounts and promotional codes

### 5. Dashboard Development

Built an interactive Power BI dashboard featuring:

* Total Sales
* Average Purchase Value
* Category Performance
* Customer Segmentation
* Subscription Analysis
* Purchase Trends
* Key Performance Indicators (KPIs)

### 6. Reporting & Presentation

* Created a detailed analytics report summarizing findings.
* Developed a professional presentation using Gamma AI and PowerPoint.

## How to Run

### Python Analysis

1. Clone the repository.
2. Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open the Jupyter Notebook:

```bash
jupyter notebook
```

4. Run all cells in `customer_behaviour_analysis.ipynb`.

### SQL Analysis

1. Import the dataset into PostgreSQL, MySQL, or SQL Server.
2. Execute queries from `customer_behaviour_analysis_sql.sql`.

### Power BI Dashboard

1. Open `Customer_behaviour_dashboard.pbix`.
2. Refresh the data source if needed.
3. Explore interactive visualizations and KPIs.
